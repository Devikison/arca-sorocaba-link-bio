# ARCA Sorocaba — Link na Bio

Página de link na bio da ARCA Sorocaba, para uso no link do perfil do Instagram (@arca_sorocaba).

- Página única e responsiva (`index.html`), com a mesma identidade visual do site principal (arcasorocaba.com.br): mesma paleta azul, tipografia (Poppins/Montserrat), logo e padrão de PIX.
- Conteúdo e estrutura seguem a documentação da tarefa "8. Link da Bio (Instagram)" no ClickUp.
- Não inclui botão para o Instagram, já que esta página é o destino do link da bio do próprio Instagram.

## Publicar (GitHub Pages)

1. Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
2. (Opcional) Adicionar um domínio próprio via arquivo `CNAME`, ex.: `link.arcasorocaba.com.br`.

## Editar links

Os links de destino (Guardião, Eventos, Bazar, WhatsApp, PIX, endereço) estão diretamente no `index.html`, dentro da seção `<nav class="links">` e dos blocos seguintes.
